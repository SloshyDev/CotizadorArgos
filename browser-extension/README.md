# Extensión Cotizador Argos

1. En la carpeta raíz del proyecto, ejecuta `npm install` y luego `npm run build:extension`.
2. Abre `chrome://extensions` en Chrome o `edge://extensions` en Edge.
3. Activa **Modo de desarrollador**.
4. Selecciona **Cargar descomprimida** y elige la carpeta `dist/cotizador-argos-extension`.

La extensión queda disponible desde el icono de extensiones del navegador. No requiere Outlook, cuenta Microsoft ni conexión a un servidor para generar las cotizaciones.
