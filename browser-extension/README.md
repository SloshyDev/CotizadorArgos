# Instalación de Cotizador Argos

Esta carpeta contiene una extensión para Chrome, Edge y otros navegadores basados en Chromium. La extensión genera cotizaciones en PDF de un seguro por fallecimiento y funciona localmente, sin enviar los datos capturados a un servidor.

## Instalar

1. Guarda esta carpeta en una ubicación permanente. No la borres ni la muevas después de instalarla.
2. Abre `chrome://extensions` en Chrome o `edge://extensions` en Edge.
3. Activa **Modo de desarrollador**.
4. Selecciona **Cargar descomprimida**.
5. Elige esta carpeta, la que contiene el archivo `manifest.json`.
6. Abre el menú de extensiones del navegador y fija **Cotizador Argos** para tenerlo siempre visible.

## Usar

1. Selecciona el icono de Cotizador Argos.
2. Escribe el nombre del asegurado, si lo deseas.
3. Captura su edad o RFC.
4. Selecciona **Generar cotización PDF**.

El navegador descargará directamente el documento con los tres planes disponibles.

## Actualizar

Descarga la versión nueva, reemplaza los archivos de esta carpeta y selecciona **Recargar** en la pantalla de extensiones del navegador.

## Ayuda

- Si no aparece el icono, abre el menú de extensiones y selecciona el símbolo de fijar.
- Si el PDF no se descarga, revisa que el navegador permita descargas y vuelve a intentarlo.
- La tarifa disponible cubre edades de 50 a 70 años.
